# Certified Concealed — E-Book Rewriting Rules

## Brand Identity

- **Brand Name:** Certified Concealed
- **Product Line:** "Know Your Ammo" — The Complete Self-Defense Ammunition Guide
- **Tone:** Authoritative, educational, practical. Written by an expert instructor speaking directly to serious carriers. Not academic, not casual — professional and approachable.
- **Audience:** Concealed carry permit holders who want to move beyond "whatever the gun store recommended" to become informed ammunition buyers.

---

## Legal Compliance Rules (NON-NEGOTIABLE)

### 1. 100% Original Language
Every sentence must be completely rewritten. Do NOT copy phrases, sentences, or distinctive phrasing from the source. This means:
- Restructure every paragraph (change the order of ideas)
- Use different vocabulary and sentence structures
- Change examples, analogies, and metaphors
- If the source says "the round punches through denim like butter" — you write something completely different like "heavy clothing presents minimal resistance to properly designed expanding projectiles"
- When in doubt, rewrite MORE aggressively

### 2. Remove All Author Names
- Delete every mention of the original author(s), contributors, editors, and photographers
- Remove bylines, "about the author" sections, acknowledgments
- Do not reference the original publication by name
- Replace with neutral phrasing: "experienced instructors," "professional trainers," "ballistic researchers"

### 3. Neutral Product Mentions
- Do NOT endorse or promote specific brands as if paid to do so
- Products/brands CAN be mentioned as examples in educational context
- Use phrasing like: "loads such as those from major manufacturers," "several well-known defensive ammunition lines"
- If the source says "The Hornady Critical Defense is the best .380 round" → rewrite as "Premium .380 loads designed for short-barrel reliability — such as those with polymer-tipped cavity designs — consistently outperform conventional hollow-points"
- Generic category descriptions are always safe: "bonded-core loads," "polymer-tipped hollow-points," "all-copper expanding projectiles"

### 4. No Trademark/Copyright Issues
- Do not reproduce tables, charts, or data sets verbatim from the source
- Recreate any data tables using different formatting, rounding, or organization
- Do not copy image captions — write entirely new descriptive placeholder text

## Content Rewriting Method

### For Each Chapter:

1. **Read the entire source chapter first** — understand the key teachings
2. **Identify the core knowledge points** — what does the reader NEED to learn?
3. **Outline your rewritten version** — restructure the flow:
   - Change the order of sections where it makes sense
   - Split long sections or combine short ones
   - Add new section headings that differ from the original
4. **Write each section from scratch** using only the knowledge points
5. **Add value where possible:**
   - Include "Key Takeaway" callout boxes at the end of major sections
   - Add image placeholders with rich descriptive text
   - Expand thin sections with deeper technical explanation
   - Add practical advice the source may have missed

### Structural Elements Per Chapter:

```
Chapter Number       → "Chapter X"
Chapter Title        → Descriptive, different from source title
Image Placeholder    → [IMAGE: detailed description of what should be shown]
Opening Paragraphs   → 2-3 paragraphs introducing the chapter topic
Section Heading      → Bold heading for each major topic
Body Paragraphs      → Detailed prose, educational tone
Key Takeaway Box     → 1-2 per chapter, summarizing the critical lesson
Closing              → Natural ending, no "in the next chapter" transitions
```

## Formatting Specifications

### Font & Typography
| Element | Font | Size | Style |
|---------|------|------|-------|
| Chapter Number | Georgia | 11pt (22 half-points) | Bold |
| Chapter Title | Georgia | 15pt (30 half-points) | Bold |
| Section Heading | Georgia | 15pt (30 half-points) | Bold |
| Body Text | Georgia | 12pt (24 half-points) | Regular |
| Image Placeholder | Georgia | 11pt (22 half-points) | Italic, color #666666, centered |
| Key Takeaway Box | Georgia | 13pt (26 half-points) | Bold + Italic |

### Page Layout
- **Page Size:** US Letter (8.5" × 11")
- **Margins:** 1 inch all sides
- **Line Spacing:** 1.5 lines (360 in docx units) for body text
- **Paragraph Spacing:** 200 after for body, 300 before/200 after for headings

### Key Takeaway Box Format
- Left border: grey (#999999), 6pt, 10pt space
- Indent: 720 left and right
- Spacing: 300 before, 300 after
- Text starts with "Key Takeaway: " in bold italic

### Chapter Breaks
- Each chapter starts on a new page (pageBreakBefore on Chapter Number paragraph)

### Part Divider Pages
- "PART X" — Georgia, 24pt (48 half-points), bold, centered, 4000 spacing before
- Subtitle — Georgia, 18pt (36 half-points), bold, centered, UPPERCASE
- Followed by page break

## Image Placeholders

Every chapter should include 2-4 image placeholders formatted as:

```
[IMAGE: Detailed description of what the image should show, including composition, 
subjects, lighting, and educational purpose]
```

Good examples:
- `[IMAGE: Cross-section diagram showing four defensive bullet types before and after impact — conventional JHP, bonded-core, polymer-tipped, and solid copper — with expanded diameters labeled]`
- `[IMAGE: Side-by-side comparison of 9mm, .40 S&W, and .45 ACP cartridges standing upright next to their expanded bullets recovered from gelatin testing — ruler for scale]`

Bad examples:
- `[IMAGE: Bullets]` ← too vague
- `[IMAGE: Photo from page 47 of the original book]` ← references source

## Quality Checklist (Run After Each Chapter)

- [ ] Zero copied phrases from source (read side by side to verify)
- [ ] No author names anywhere
- [ ] No brand endorsements (educational mentions only)
- [ ] Chapter has 2-4 image placeholders
- [ ] Chapter has 1-2 Key Takeaway boxes
- [ ] All sections have descriptive headings
- [ ] Technical accuracy maintained (don't change facts/data)
- [ ] Tone is consistent: authoritative, educational, practical
- [ ] Length is comparable to or greater than source chapter
- [ ] Flows naturally without referencing other publications
